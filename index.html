03 / ГЕОМЕТРИЯ ФУНКЦИИ

Почему поиск продолжается

1. Производная всегда положительна

∂f/∂x₁ = 1 + 0,01e0,01x₁ + 0,11x₂ > 1

Уменьшение первой координаты улучшает значение функции в любой точке. Стационарных точек нет, а норма градиента всегда больше 1.

2. Явное направление неограниченного спуска

x(t) = (1 − 11t; t),   t ≥ 0
f(x(t)) = 1 + e0,01 − 12,4t → −∞

Вдоль этой прямой показатель экспоненты остаётся равным 0,01. Линейная часть убывает со скоростью 12,4. Следовательно, inf f = −∞.

04 / АЛГОРИТМЫ И ФОРМУЛЫ

Как устроены методы

Д

Гаусс–Зейдель

Координаты изменяются последовательно. Для каждой координаты решается одномерная задача при фиксированных остальных переменных.

x₁k+1 = arg minu ∈ ℝ f(u, x₂k)
x₂k+1 = arg minv ∈ ℝ f(x₁k+1, v)
  1. Проверить точки со смещениями +h и −h.
  2. Удваивать смещение в направлении убывания до получения тройки точек, средняя из которых лучше соседних.
  3. На найденном интервале применить золотое сечение с точностью ε/10.
  4. После полного прохода по координатам проверить ‖xk+1 − xk‖₂ ≤ ε.

Защита программы: не более 12 удвоений при локализации. Для функции 1 интервал не находится уже на первой координате. Пробные точки показаны отдельно; завершённых циклов метода — 0. Золотое сечение реализовано, но для этой функции до него выполнение не доходит.

К

Конфигурации Хука–Дживса

Используется вариант «а» из раздела 1.5.2 методички: постоянный коэффициент λ = 1. Производные не вычисляются.

z ← исследование окрестности xk
xk+1 = xk + λ(z − xk),   λ = 1
  1. Из текущей базисной точки последовательно проверить +h и при неудаче −h по каждой координате.
  2. Сохранять каждое найденное улучшение при исследовании следующей координаты.
  3. Если улучшение найдено, принять z как новую базисную точку.
  4. Если улучшения нет, уменьшить h вдвое. Завершить поиск при h ≤ ε.

Начальный шаг h = 0,5. При заданной функции уменьшение x₁ улучшает результат на каждом проходе, поэтому шаг не дробится. Лимит 120 итераций ограничивает длительность эксперимента и не означает достижения точности.

Вывод

Метод Гаусса–Зейделя требует существования минимума в каждой одномерной задаче. Для функции 1 это условие нарушено на первой координате. Метод конфигураций продолжает находить улучшения, но не достигает критерия h ≤ ε. Убывание f само по себе не доказывает сходимость: обе реализации отражают отсутствие конечного минимума у заданной функции.

Сравнивать эти результаты как скорость нахождения минимума нельзя. Здесь сравниваются поведение алгоритмов и затраты вычислений до защитной остановки.
